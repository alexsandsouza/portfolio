## 📋 Sobre o Projeto

Portfólio profissional e plataforma educacional completa, desenvolvida com foco em **Alta Performance**, **Design Cyber Tech** e **Experiência do Usuário (UX)**. Além de vitrine profissional, o projeto integra um **sistema de avaliações online interativas** para disciplinas da graduação em Tecnologia.

### 🎯 Funcionalidades Principais

| Módulo | Descrição |
|--------|-----------|
| 🏠 **Portfólio** | Hero section, projetos, skills, trajetória profissional, depoimentos |
| 📚 **Plataforma FAMETRO** | Sistema de provas online para múltiplas disciplinas da graduação |
| 🏆 **Rankings** | Classificação em tempo real com Firebase Firestore |
| 🎓 **Mentoria** | Página de captação, contrato digital e área exclusiva de alunos |
| 🔗 **Links** | Agregador de links profissionais estilo Linktree |
| 🛡️ **Hackers do Bem** | Hub dedicado ao programa de segurança cibernética |

## 📂 Estrutura do Projeto

```
portfolio/
├── public/                    # Assets estáticos e imagens
├── src/
│   ├── components/            # Componentes reutilizáveis (Navbar, Reveal, etc.)
│   ├── sections/              # Seções da página principal (Hero, About, Skills...)
│   ├── pages/
│   │   ├── fametro/           # 📚 Plataforma educacional
│   │   │   ├── disciplinas/   # Atividades por disciplina
│   │   │   │   ├── EngSoftware/       # Engenharia de Software
│   │   │   │   ├── Requisitos/        # Requisitos de Software
│   │   │   │   ├── POO/               # Programação Orientada a Objetos
│   │   │   │   ├── SO/                # Sistemas Operacionais
│   │   │   │   ├── HTMLSemantic/      # HTML Semântico
│   │   │   │   └── Matrizes/          # Matrizes e Determinantes
│   │   │   └── rankings/     # Páginas de classificação
│   │   ├── hackersdobem/      # 🛡️ Hub Hackers do Bem
│   │   └── mentorship/        # 🎓 Sistema de mentoria
│   ├── data/                  # Centralização de conteúdo textual
│   ├── hooks/                 # Lógica de UI isolada (efeitos de mouse)
│   └── config/                # Configurações (Firebase, etc.)
├── index.html
├── vite.config.js
└── package.json
```

## 📚 Módulo Educacional - FAMETRO

Sistema completo de **avaliações online interativas** desenvolvido para a graduação em Tecnologia:

| Disciplina | Tipo | Questões | Recursos |
|:-----------|:-----|:---------|:---------|
| Engenharia de Software | Revisão N2 | 8 objetivas + discursiva | Modelos A/B, Ranking, Gamificação |
| Requisitos de Software | Revisão N2 | 8 objetivas + discursiva | Modelos A/B, Ranking, Gamificação |
| Programação OO (Java) | Múltiplas atividades | Variável | Rankings por atividade |
| Sistemas Operacionais | Múltiplas atividades | Variável | Rankings por unidade |
| HTML Semântico | Atividade prática | Variável | Ranking dedicado |
| Matrizes | Lab prático | Variável | Ranking dedicado |

### 🏆 Sistema de Gamificação
- **Badges dinâmicos:** 🎯 Primeiro Acerto · 🔥 Em Chamas · ⚡ Metade Vencida · 💎 Gênio Analítico · 🚀 Rápido e Preciso · 🏆 Revisor Mestre
- **Rankings em tempo real** com Firebase Firestore
- **Modelos de prova A e B** com randomização

## 🚀 Como Executar Localmente

```bash
# Clone o repositório
git clone https://github.com/alexsandsouza/portfolio.git

# Acesse a pasta
cd portfolio

# Instale as dependências
npm install

# Execute em modo de desenvolvimento
npm run dev
```

O projeto estará disponível em `http://localhost:5173`
